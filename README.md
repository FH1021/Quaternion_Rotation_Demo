## 使用方法

### 方式一：Unity 编辑器运行（推荐先这样）

1. 打开 Unity Hub → **Add** → 选择本工程文件夹 `Unity四元数旋转演示`，用 **2022.3 LTS** 打开；
2. 等待首次导入完成（Console 应无红色报错）；
3. 双击 `Assets/Scenes/QuaternionDemo.unity`，点 **Play**。

场景布局（摄像机正前方，五个立方体同深度 z=0 并排、互不遮挡；FromPose/ToPose 略靠前）：

| 物体        | 位置            | 颜色  | 含义                                            |
| --------- | ------------- | --- | --------------------------------------------- |
| QuatCube  | (−3.2, 0, 0)  | 蓝色  | 演示一：四元数模式，q = Δq·q（世界轴）或 q = q·Δq（局部轴），无万向节死锁 |
| EulerCube | (−1.6, 0, 0)  | 橙色  | 演示一：欧拉角模式，欧拉角直接累加，X 转到 ±90° 时出现万向节死锁          |
| SlerpCube | (0, 0, 0)     | 绿色  | 演示二：Slerp 球面插值主体，在 FromPose ↔ ToPose 之间循环     |
| LerpCube  | (1.6, 0, 0)   | 灰色  | 演示二：Lerp 线性插值对照（非匀速、会缩放，与 Slerp 同步）           |
| MathCube  | (3.2, 0, 0)   | 青色  | 演示三：手写四元数代数（MyQuat）绕轴旋转 + 5 项自检               |
| FromPose  | (−0.5, 0, −2) | 无渲染 | 演示二起点姿态标记（Slerp 的 from）                       |
| ToPose    | (0.5, 0, −2)  | 无渲染 | 演示二终点姿态标记（绕 Y 90°）                            |

演示一的蓝橙两个立方体**同步接收完全相同的输入**（同一旋转轴、同一角度），  
一个面板同时驱动，便于并排观察两种表示的行为差异。

### 方式二：打包成 Windows 程序

- 在 Unity 内：菜单 **豆包工具 → 打包 Windows 64 位**，产物在 `Build/QuaternionDemo.exe`；
- 或命令行：双击 `build.bat`（自动定位 Unity 编辑器路径，日志见 `build.log`），成功后双击 `run.bat` 运行。
- **注意**：命令行打包需要 Unity 许可已激活（与之前 ParametricCurveLab 相同的前提）。

## 演示内容

### 演示一：四元数 vs 欧拉角（蓝/橙，同一面板驱动）

- **旋转轴 X / Y / Z**：滑块调整旋转轴方向（自动单位化）；
- **旋转角**：滑块设置单次旋转角度，点 **旋转一次** 或勾选 **自动旋转**；
- **世界轴 / 局部轴**：四元数模式的两种合成顺序——左乘 `q = Δq·q`（世界轴）vs 右乘 `q = q·Δq`（局部轴）；
- **重置**：两个立方体回到初始姿态；
- 面板实时显示：蓝色立方体的四元数四分量与 |q|、等效欧拉角，橙色立方体的欧拉角。

### 演示二：Slerp vs Lerp（绿/灰，独立面板）

- SlerpCube（绿）沿单位四元数球面上的**测地线**旋转：匀速、无缩放；
- LerpCube（灰）对四元数分量做**线性插值**：中途角速度变化，且 q 长度偏离 1（视觉上“缩小”）；
- 两物体同步循环，选中后可拖动 **progress** 滑块单步观察；Scene 视图中  
  FromPose/ToPose 位置有半透明线框球标记起点与终点姿态。

### 演示三：手写四元数代数自检（青，独立面板）

- 在 `MyQuat`（完全不依赖 UnityEngine.Quaternion）上实现：Hamilton 乘法、共轭/逆、  
  范数、轴-角构造、`v' = q·v·q⁻¹` 旋转；
- 面板逐项输出 **5 项自检结果**（乘法封闭性、逆与共轭、范数保持、轴-角还原、旋转保长/保角），  
  全部为 √ 时说明手写实现与 Unity 官方 Quaternion 一致；
- **绕轴旋转**按钮用自写代数旋转青色立方体，可直接对照 Unity 内置旋转。

### 关键实验（死锁对比）

1. 角度设 **90°**，对两个立方体同时连点 **旋转一次**（绕世界 Y 轴）：
   - 蓝色立方体：转 4 次后（累计 360°）回到初始姿态，全程平滑；
   - 橙色立方体：欧拉角数值直接累加，Y 数值从 90→180→270→360→90 循环，视觉上正常。
2. 把旋转轴改为 **X**，角度 **90°** 连点：
   - 蓝色立方体：绕世界 X 轴转到 90°，此时若再点 Y 轴旋转，仍能正确绕世界 Y 轴转；
   - 橙色立方体：欧拉角 X=90° 到达死锁点，再旋转 Y / Z 时两个轴“糊”在一起、  
     失去一个自由度——这就是**万向节死锁**（蓝色永远不会出现）。

### Scene 视图可视化（选中 QuatCube 查看）

- 红色双向射线 = 当前旋转轴；灰色 = 未旋转的基向量；RGB = 旋转后的基向量；
- 洋红色 = 示例向量 (1,0,0) 旋转后的位置（验证 v' = q·v·q⁻¹）；
- 蓝橙两立方体上方显示文字标签与实时四元数/欧拉角分量（仅编辑器内有效）；
- 选中 SlerpCube 时，FromPose/ToPose 处显示线框球标记与朝向。

## 数学原理

### 1. 四元数定义

`q = w + x·i + y·j + z·k`，记作 `(w, x, y, z)`；旋转四元数满足归一化 `|q|² = w²+x²+y²+z² = 1`。

### 2. 轴-角构造

绕单位向量 `u` 旋转 θ：`q = (cos θ/2, sin θ/2 · u)`。  
例：绕 Y 轴 90°，θ/2=45°，`q = (0.7071, 0, 0.7071, 0)`。

### 3. 旋转公式

`v' = q · p · q⁻¹`（p 为 v 的纯四元数 `(0, v)`；q 归一化时 `q⁻¹ = q* = (w, −x, −y, −z)`）。  
例：`(0.7071, 0, 0.7071, 0)` 旋转 `(1,0,0)` → `(0,0,−1)`（Unity 左手系，绕 +Y 正向 90° 把 +X 转到 −Z，  
与 `Quaternion.AngleAxis(90, Vector3.up) * Vector3.right` 一致）。

### 4. 旋转合成

先 q₁ 后 q₂：`q = q₂ · q₁`。Hamilton 乘积：  
`(w₁,v₁)·(w₂,v₂) = (w₁w₂ − v₁·v₂, w₁v₂ + w₂v₁ + v₁×v₂)`。  
例：q₁=绕X轴90°，q₂=绕Y轴90°：`q₂·q₁ = (0.5,0.5,0.5,−0.5)`，`q₁·q₂ = (0.5,0.5,0.5,0.5)`，  
**二者不等** → 旋转不可交换（演示中“世界轴/局部轴”的本质区别）。

### 5. 为什么四元数没有万向节死锁

- 欧拉角：3 角度 + 固定顺序。中间轴 ±90° 时首尾轴几何重合 → 失去一个自由度（死锁）。
- 四元数：一个“轴+角”紧凑表示（4 个数），没有“轴重合”概念，任何归一化四元数都是合法姿态，  
  且可直接球面插值。
